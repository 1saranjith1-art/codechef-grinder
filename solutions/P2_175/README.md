## Problem Summary
The problem asks us to determine the position of a specific ticket in a queue based on a given pattern. Given an integer $N$, we need to find the value associated with the $N$-th position in the sequence generated by the ticket distribution rules.

## Intuition & Mathematical Observation
By observing the sequence generated for small values of $N$, we can identify a pattern based on whether $N$ is even or odd:

1.  **Case $N = 1$**: The output is simply $1$.
2.  **Case $N$ is odd ($N > 1$)**: The pattern follows the formula $\frac{N-1}{2}$.
3.  **Case $N$ is even**: The pattern follows the formula $\frac{N}{2} + 1$.

By testing these conditions against the sample cases, we can confirm that this logic correctly maps the input $N$ to the required output. The logic handles the base case ($N=1$) separately to avoid potential issues with the odd-number formula.

## Complexity Analysis
- **Time Complexity**: $O(T)$, where $T$ is the number of test cases. Each test case is solved in $O(1)$ constant time using simple arithmetic operations.
- **Space Complexity**: $O(1)$, as we only use a few variables to store the input and output, regardless of the size of $N$.

## Solution Code

```cpp
#include <iostream>
using namespace std;

int main() {
    // Optimize I/O operations
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        
        // Apply the derived mathematical pattern
        if (n == 1) {
            cout << 1 << "\n";
        } else if (n % 2 != 0) {
            // For odd numbers > 1
            cout << (n - 1) / 2 << "\n";
        } else {
            // For even numbers
            cout << (n / 2) + 1 << "\n";
        }
    }
    return 0;
}
```
